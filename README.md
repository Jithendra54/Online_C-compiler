# Online C Compiler

A browser-based interface for writing and working with C programs. This project explores the frontend experience of an online coding environment.

## Overview

The application provides a simple workspace for entering C source code and viewing program output through its web interface.

## Technology Stack

- React
- TypeScript
- JavaScript
- Vite
- HTML and CSS

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL printed by Vite in your browser.

### Create a production build

```bash
npm run build
```

## Project Structure

The source code and configuration are organized around the Vite application. Refer to the repository files for the current component and configuration layout.

## Scope and Notes

This repository is a development project for a browser-based C programming interface. The README does not claim that compilation is performed securely in an isolated production sandbox. Do not use it to run untrusted code or expose it as a public multi-user compiler until execution is implemented and validated with appropriate server-side isolation, resource limits, and security controls.
